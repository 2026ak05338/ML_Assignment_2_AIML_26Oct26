# Bank Marketing Subscription Prediction

A machine-learning classification project that compares five classifiers for predicting whether a client subscribed to a term deposit (`y = yes`) after a bank marketing campaign. It includes a training/evaluation script and a Streamlit interface.

## Project overview

The project trains and compares five supervised classification models on the UCI Bank Marketing dataset. The target is the `y` column, recording whether the client subscribed to a term deposit. The results below are from the supplied `metrics.csv`.

Models compared:
1. Logistic Regression
2. Decision Tree
3. Support Vector Machine (SVM; calibrated linear SVM in the optimized training version)
4. K-Nearest Neighbors (KNN)
5. Naive Bayes

*Values are copied from the provided `metrics.csv`, rounded to four decimal places (time to two decimal places).*

### Results interpretation

- **Highest ROC-AUC:** SVM (0.9072), closely followed by Logistic Regression (0.9056), giving the strongest ranking performance in this run.
- **Highest accuracy and precision:** Logistic Regression (0.9012 and 0.6440). Its recall is 0.3488, so it identifies a smaller share of actual subscribers.
- **Highest recall:** Naive Bayes (0.5198), identifying the largest share of actual subscribers among these models, with lower precision (0.4059).
- **Highest F1-score:** Decision Tree (0.4710), narrowly above Naive Bayes (0.4559) and Logistic Regression (0.4525).
- **Training time:** Naive Bayes was fastest (0.34 s); KNN was slowest (43.45 s) in the recorded run.
- Accuracy is high across models, while positive-class precision and recall are lower. Accuracy alone therefore does not describe how well the classifiers find subscribers. The preferred model depends on whether avoiding false-positive recommendations (precision) or catching more likely subscribers (recall) matters more.

These observations apply to this recorded run; results can vary with preprocessing, random seed, dataset version, and software/hardware.

## Metrics

- **Accuracy:** fraction of all test examples classified correctly.
- **Precision:** among predicted positives (`yes`), fraction that are truly positive.
- **Recall:** among actual positives, fraction identified by the model.
- **F1-score:** harmonic mean of precision and recall.
- **ROC-AUC:** ranking ability across classification thresholds; higher is generally better.
- **Training time:** measured model-fitting time; hardware and environment affect it.

For imbalanced targets, interpret precision, recall, F1-score, and ROC-AUC alongside accuracy. The decision threshold and model should reflect the cost of false positives versus missed subscribers.
